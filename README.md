# Mixed-Tail Quantile Functions for Extreme Value Analysis

This repository contains the reproducibility materials for the article:

Redivo, E., Farcomeni, A., and Viroli, C. (2026+). *Mixed-Tail Quantile Functions for Extreme Value Analysis* (Under review).

The repository provides the R code needed to reproduce the simulation study, empirical analysis, tables, and figures reported in the paper.

The proposed methodology is implemented in the accompanying R package `{mixqev}`, which is included in this repository. The package is provided as a convenient way to load the functions used in the paper and is intended primarily for reproducibility. The package can be installed from the local package folder after downloading this repository, or directly from GitHub with:

```r
# install.packages("remotes")
remotes::install_github("redivoe/mixed-tail-quantile-functions/mixqev")
```
